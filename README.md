## 🚀 Run Locally

```bash
git clone https://github.com/razibr246/Razib-Miah-Protfolio.git
cd Razib-Miah-Protfolio
npm install
npm run dev
```

The chat assistant on the Play page needs a `GROQ_API_KEY` environment variable.
